# الواجهة البحرية — منيو إلكتروني

هذه النسخة الأولى تحتوي على:

- واجهة زبون فاخرة ومتجاوبة.
- أقسام وأصناف ديناميكية.
- لوحة تحكم لإضافة/تعديل/حذف الأقسام.
- لوحة تحكم لإضافة/تعديل/حذف الأصناف والأسعار.
- إظهار وإخفاء الأصناف والأقسام.
- تعديل معلومات المطعم.
- تعديل صورة Hero والشعار عبر روابط الصور.
- حفظ البيانات في `localStorage`.

## التشغيل

ارفع الملفات كلها إلى مستودع GitHub Pages، ثم افتح:

`index.html`

وللوحة التحكم:

`admin.html`

## ملاحظة مهمة

هذه النسخة الأولى تحفظ البيانات في المتصفح نفسه عبر localStorage. لذلك هي مناسبة للتجربة والتصميم، لكنها ليست بعدُ نظام إدارة مركزي بين عدة أجهزة.

المرحلة التالية المقترحة: ربط المشروع بـ Firebase Firestore + Firebase Storage + Firebase Authentication، بحيث تكون لوحة التحكم خاصة بالمالك وتُحفظ البيانات والصور مركزياً وتظهر فوراً لكل الزبائن.
